Backend installation

Install the Standard and Docker controllers as separate Helm releases with installation.role: backend. Keep each in its own namespace with its required workspace storage and admission policy. The Docker release is optional.

Helm commands and values

Required Gateway

Install a release with installation.role: gateway. Provide a serving TLS Secret, a retained ReadWriteOncePod claim, backend HTTPS origins and per-principal profile grants. Cert-manager provisions and renews private controller serving and Gateway client certificates across namespaces. Each controller verifies the Gateway identity and applies the mapped backend principal's grants.

For an existing direct installation, verify Gateway profiles and HTTP/2, stop old sandboxes, retire direct access and then migrate the saved assignments in the upgraded plugin.

Gateway settings

Each Paseo daemon uses a single Gateway connection. Paths refer to files on the daemon host or inside its container.

HTTPS URL
Private HTTPS origin reachable from the Paseo daemon. The route must support HTTP/2 streams.
Token file
Absolute daemon path to the raw Gateway token.
CA file
Absolute daemon path to the CA certificate for a private TLS endpoint. Leave empty to use system trust.

Helm profiles

A profile specifies the image and a worktree volume mapping. Linked Git worktrees also need a repository mapping. Each mapping has a claimName, an absolute basePath on the daemon and an optional PVC subPath.

Administrators can also set idleMinutes, container options such as resources, podSpec options such as placement, and sidecars.

The Profiles table shows administrator-configured CPU, RAM and ephemeral-storage requests and limits for the main container, sidecars and init containers with controller and plugin v0.5.6 or later. Unset means the profile omits the field. Kubernetes admission can supply defaults. Unavailable from controller means resource metadata was absent from discovery.

Ephemeral storage covers local usage such as writable layers, logs and disk-backed emptyDir volumes. Persistent worktrees and repositories use shared RWX PVCs. Set docker.sizeLimit separately to cap the Docker state emptyDir volume.

Standard is the default for new opt-ins when the token permits it. Docker (privileged) is an optional administrator-defined profile for trusted workspaces. Its privileged sidecar shares the same worktree mount and stores Docker state on a separate disk-backed volume.

Scoped tokens

Each Gateway principal has a distinct tokenSha256 and a list of allowed profiles. Sandbox identity also includes the principal and the workspace ID.

Workspace status

Enable a workspace and save one of its authorized profiles. Standard is preselected when available. Choose Docker (privileged) explicitly. Use Refresh status to see the pod state. Stop the sandbox and wait for No sandbox before changing the profile. Stopping ends running processes and discards ephemeral state. The saved assignment and shared workspace files remain.
