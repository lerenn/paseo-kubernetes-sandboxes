Reference

Settings

  • Image: needs a shell and your tools. Required.
  • CPU / memory: requests and limits of the main container.
  • Worktree volume: claim, mount path (same path in the pod), optional sub path. Required.
  • Idle timeout: minutes before an idle pod is deleted; 0 disables it.
  • Environment Secret: optional Secret exposed as environment variables.
  • Docker-in-Docker: optional privileged sidecar, off by default.
  • Context, namespace: where pods are created.

Hooks

  • agent.open.before, terminal.create.before, command.run.before: return wrap for opted-in workspaces.
  • workspace.archive.after: deletes the workspace's pod.

Pod

Named sbx-<hash of workspace id>, labelled app.kubernetes.io/managed-by=paseo-kubernetes-sandbox, with a shared process namespace and no service account token. The main container idles; work arrives through kubectl exec.

Launcher

kube-exec.sh --namespace NS --pod POD [--context C] [--container main]
  [--cwd DIR] [--env NAME]... [--state-dir /tmp/sbx] -- command [args...]

Forwarded variable values travel as kubectl exec arguments. Use the environment Secret for credentials.

RBAC

pods: get, list, watch, create, delete; pods/exec: create; pods/log: get; persistentvolumeclaims: get.
