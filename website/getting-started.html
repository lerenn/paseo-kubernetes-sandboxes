Getting started

Install the controller in Kubernetes, then connect the Paseo daemon.

Install the controller

  1. Use Kubernetes 1.34 or later and a dedicated namespace. Pre-create the shared storage claims and prepare a sandbox image with a shell, Git and the tools agents need.
  2. Use the example Helm values to define a profile with the image, PVC names and daemon paths. Generate a separate token for each daemon and put its SHA-256 digest and permitted profiles in the values.
  3. Install the Helm chart and give each daemon a private HTTP/2-capable route to the Service. Supply the serving CA and the daemon's raw token through daemon-local files.
helm upgrade --install sandbox \
  oci://ghcr.io/lerenn/paseo-kubernetes-sandboxes/charts/paseo-sandbox-controller \
  --version 0.5.0 --namespace paseo-sandboxes --create-namespace \
  --values controller-values.yaml --wait

Administrator setup and example values

Connect Paseo

  1. On a daemon running Paseo 0.17.5 or later and Node.js 22 or later, install the plugin from the release checkout.
  2. Open Kubernetes Sandbox and enter the controller URL, absolute token path and CA path if required.
  3. Select Check connection, save the settings and select Enable sandbox for a workspace on the shared storage. Choose a profile from the authorized list. Standard is preselected when available.
  4. Open a new terminal and select Refresh status to see the workspace pod.
paseo plugin install "$PWD/plugin"
