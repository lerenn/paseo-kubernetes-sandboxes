Getting started

Apply a Role, install the plugin, then opt workspaces in.

Requirements

  • Paseo 0.17.5 or later on the daemon host.
  • kubectl on the daemon host, authenticated to a cluster.
  • A namespace with the Role from config/plugin-rbac.yaml bound to your kubectl identity.
  • A PersistentVolumeClaim holding the daemon's worktrees, mountable by the pods.
  • An image with a shell and the programs your agents need.

Install

kubectl create namespace paseo-sandboxes
kubectl apply -n paseo-sandboxes -f config/plugin-rbac.yaml
kubectl create rolebinding paseo-sandboxes -n paseo-sandboxes \
  --role=paseo-sandboxes --user=<identity>

cd plugin && npm ci
paseo plugin install "$PWD"

Set up from Paseo

  1. Open Kubernetes Sandbox from the sidebar.
  2. In Settings, set the image, worktree claim and mount path. Save.
  3. In Cluster, choose context and namespace and run Check cluster.
  4. In Workspaces, tick the workspaces that run in a pod. Save.
  5. Launch an agent or terminal in one of them. The first launch creates the pod.

Full guide: docs/setup.md.
